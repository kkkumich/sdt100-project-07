## Запуск

Требуется JDK 21. В IntelliJ: открыть проект, выбрать JDK, отметить src как Sources Root. Каждая часть запускается своим main. Рабочая папка — корень этого проекта.

Из PowerShell:

```powershell
$sourceFiles = @(Get-ChildItem src -Recurse -Filter *.java | ForEach-Object FullName)
javac -encoding UTF-8 -d build @sourceFiles
java -cp build part1_bubble_sort.Main
java -cp build part2_trace.Main
```

## Что показать на защите

Введи 5, -1, 5, 0, 2. Покажи массив до и после сортировки. Открой trace.html: в нём каждое сравнение, а переставленные пары выделены жирным.

## Как объяснить

Bubble sort сравнивает соседей и меняет их местами, если они стоят в неправильном порядке. После прохода максимум неотсортированной части оказывается справа. Поэтому внутренняя граница уменьшается; если за проход нет обменов, сортировка заканчивается досрочно.

## Возможные вопросы

- **Сложность?** O(n²) в среднем и худшем случае, O(n) в лучшем с флагом swapped. Дополнительная память O(1).
- **Стабильная ли сортировка?** Да: равные значения не меняются местами, потому что сравнение строгое >.
- **Зачем временная переменная?** Чтобы не потерять значение первого элемента при обмене.
